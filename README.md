# CS2-Mamaril-Justin
## Version 2 - Code with input validation
* **Input & Validation Rules:**
  * **Passenger Name:** Ensures the name is not left empty using `.strip()`.
  * **Distance:** Ensures distance is a number greater than 0.
  * **Passengers:** Ensures passenger count is a positive whole number using `.isdigit()`.
* **Process:** Asks for re-entry until valid input is given, then calculates total fare.
* **Output:** Displays passenger name and total fare in PHP.
